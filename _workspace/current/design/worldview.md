## 전제

Cinder Court(잿불 법정)는 **기억의 감옥**이다. 배신당한 서약이 Lantern
Reaver(등불 사냥꾼)의 기억을 수호자 메아리(guardian echoes) 속에 봉인했다.
Reaver는 랜턴을 들고 법정을 강하하며 메아리를 되찾고, 법정을 기억의 감옥으로
만든 타락한 집행관(corrupt enforcer)의 배신을 폭로한다.

## 공간 계보 (9스테이지 = 3부작)

| 부 | 스테이지 | 공간 의미 |
|---|---|---|
| 1부 재판정 (기록) | cinder-span 재의 다리 → ember-gallery 불씨 회랑 → abyss-chancel 서약의 성당 | 법정으로 향하는 기록의 공간 — 서약과 증언이 쌓인다 |
| 2부 증언 (판결) | witness-well 증언의 우물 → echo-throne 메아리 왕좌 → ash-verdict 재의 판결 | 증언이 왜곡되고 판결이 내려진다 |
| 3부 집행부 (형 집행) | cinder-sluice 재의 수문 → ember-bastion 불씨 요새 → ash-march 재의 행진 | 판결의 집행 기계 — 기록 말소(수문), 위증 방벽(요새), 형 집행(행진) |

## 명명 규약 (G1 감사 기준)

- 스테이지 id: `{재/불씨/메아리 계열}-{공간}` 소문자 하이픈. 한글명은 2-5자
  명사구. 영문 kicker는 대문자.
- 보스: 직책명(Warden/Tactician/Sovereign/Keeper/Sentinel/Magistrate) —
  법정 관료제 어휘만 사용. 고유명사 금지(원작/타작품 이름 금지).
- 색 언어: 숯(charcoal) 바탕 + 엠버 오렌지(위험/불) + 스펙트럴 시안(기억/
  수호자) + 골드(보상/판결). 스테이지 액센트는 이 팔레트의 변조만 허용.
- 기믹 서사: 모든 해저드는 법정 기능의 물화(수문=말소, 방벽주=위증 보호,
  재의 장벽=집행). 순수 장식 해저드 금지.
- 대사 화자: 감시자(내레이션) / 보스(직책 화자) / 워든(회고). 존대 없는
  선고체.
