## 2. SORTIE — 4그룹 아코디언

### 2.1 그룹 정의 (worldview §공간 계보가 유일 출처)

| # | 헤더 | 스테이지 | 색 |
|---|---|---|---|
| 0 | `제1부 기록` | cinder-span, ember-gallery, abyss-chancel | 시안 (기억/수호자) |
| 1 | `제2부 증언` | witness-well, echo-throne, ash-verdict | 골드 (보상/판결) |
| 2 | `제3부 집행` | cinder-sluice, ember-bastion, ash-march | 엠버 (위험/불) |
| 3 | `훈련장` | 등급선택 + 시련 5 | 시안 |

**새 색을 만들지 않는다.** 3부작이 이미 색 언어에 대응한다(기록=기억=시안,
증언=판결=골드, 집행=위험=엠버). G1 감사 대상은 헤더 문자열 3개뿐이고 전부
worldview 표 §13의 부(部) 이름 그대로다.

### 2.2 기하 (실측 산술)

```
헤더 44u, 헤더 피치 48u, 그룹 간격 2u, 카드 피치 70u (기존 동결값), 상단 6u
뷰포트 434u (변경 없음: 620 − 174 − 12)
```

| 펼친 그룹 | 콘텐츠 높이 | 가시율 | 스크롤 |
|---|---|---|---|
| 1부 / 2부 / 3부 (3행) | `4×50 + 3×70 + 6` = **416u** | **100%** | 불필요 |
| 훈련장 (6행) | `4×50 + 6×70 + 6` = **626u** | **69.3%** | 필요 |
| 현행 (비교) | 1058u | 41.0% | 항상 |

훈련장 펼침 시 시련 행 배치: 헤더 −156..−200, 등급 −206..−274,
시련0 −276..−344, 시련1 −346..−414, 시련2 −416..−484(부분).
→ **완전 가시 본문 행 3** (등급선택 + 시련 2). 현행은 첫 시련 top 706u로 **0행**.
PM 밴드 `mastery_surface_rows_visible ≥ 1` 충족 (실측 0 → 3).
밴드 metric은 등급선택을 포함한다 — 시련 진입의 전제이고 `interactable`을
같은 `open = PrologueDone`이 결정한다.

*(주: PM 706u / QA 708u 2u 불일치는 정수 판정이라 결과 불변 — 양쪽 기록 유지.)*

### 2.3 펼침 규칙

- **정확히 한 그룹만 펼쳐진다.** 높이 예산을 보장하는 것은 이 제약이다.
- 기본 펼침 = **다음 목표가 속한 그룹**. 로비를 열면 항상 "지금 여기"가 열려 있다.
- 헤더를 누르면 그 그룹이 펼쳐지고 핀이 선다. 핀은 `Hide()`에서 해제 —
  **로비를 나갔다 오면 다시 자동 추종**, 머무는 동안엔 내 선택이 유지된다.
- 접힌 그룹도 헤더에 `n/3`을 표시한다. 접혀도 진행은 보인다.

### 2.4 헤더 구성

```
[제1부 기록                      3/3  ▼]     ← 펼침
[제2부 증언                      1/3  ▶]     ← 접힘
```
카레트 `▼`/`▶`는 폰트 기존 글리프. 카운트는 `ClearedMask` 비트합.
훈련장 그룹은 `n/5` (판결 등급 시련 수, `CampaignStore.BestTier`).

## 3. 잠금 사유 — 대비가 설계를 강제했다

### 3.1 문자열

| 사유 | 서브라인 |
|---|---|
| 선행 미클리어 | `{별칭} • 선행: {선행 스테이지 한글명}` |
| 프롤로그 미완 | `{별칭} • 점화 훈련 필요` |
| 해금됨(미클리어) | `{별칭} • 보상: {동행명}` (현행 유지) |
| 클리어됨 | `{별칭}` (현행 유지) |

별칭을 남기는 이유: 별칭이 **N8 예고**다. 잠긴 카드가 "무엇을 연습하게 될지"를
계속 말해야 한다. 사유만 남기면 예고를 잃는다.

### 3.2 대비 — 측정이 배치를 결정했다 `[OBSERVED]`

잠긴 카드는 `CanvasGroup.alpha = 0.45`다(`LobbyView.cs:244`). 합성 후 대비:

| 색 | 원색 | alpha 0.45 합성 | AA 4.5 |
|---|---|---|---|
| 골드 | 12.20 | **3.07** | ✗ |
| 시안 | 7.84 | **2.31** | ✗ |
| InkDim | 8.69 | **2.48** | ✗ |
| 잠금 회색 | **4.38** | **1.71** | ✗✗ |

**어떤 색도 0.45 뒤에서는 통과하지 못한다.** 잠금 회색은 원색조차 4.38로 미달이다.

확정: **사유 라벨에 `CanvasGroup { alpha = 1, ignoreParentGroups = true }`를 달아
감쇠 밖으로 뺀다.** 색은 **InkDim (8.69:1)**.

이 배치가 옳은 이유는 의미론이다. 카드가 흐린 것은 **"지금 누를 수 없다"**는
신호이고, 사유는 **정확히 그 흐림을 설명하는 문장**이다. 설명이 함께 흐려지면
설명이 아니다. 행 alpha를 올리는 대안은 9장 전체의 잠금 문법을 바꾸므로 기각.

## 4. `다음 재판` 표식 — 공개형, 정확히 1장

### 4.1 목표 선정 (순수 함수)

```
NextTarget(data):
  1. !PrologueDone            → Prologue
  2. 최소 인덱스의 (해금 && 미클리어) 스테이지  → Stage(i)
  3. !MasteryComplete         → 최소 인덱스의 판결 미달 시련  → Trial(i)
  4. 그 외                    → None      (전부 끝낸 정당한 종단)
```

- 인덱스가 전순서라 **동률이 없다** — 슬롯 수는 구조적으로 0 또는 1.
- 4번 `None`은 실패가 아니다. QA T-A1의 "정확히 1개"는 **3번까지 도달 가능한
  상태**에 대한 조건이고, `None`은 별도 케이스로 판정한다.
- `Stage(i)`는 `StageCatalog.IsUnlocked`(`:526`)를 그대로 쓴다 — 규칙 복제 금지.

### 4.2 표시

- 대상 카드 상태 라벨이 `강하 가능` → **`다음 재판`** (엠버)
- 대상 그룹이 기본 펼침
- SORTIE 아이브로 부제 = `정화 n/9` + 대상 별칭

추천이 아니라 **공개**다: 무엇이 다음 문인지 알려주고, 갈지 말지는 플레이어가
고른다. 다른 해금 스테이지의 `강하` 버튼은 그대로 눌린다.

## 5. SANCTUM — 배지와 컨텍스트

### 5.1 배지 규칙 (PM 밴드 `badge_misdirect_relics ≤ 2` 집행)

| 탭 | 통화 | 배지 조건 |
|---|---|---|
| 성장 | Points | `Points > 0 && 어느 스탯 < 10` |
| 군단 | 무료 | 보유 동료 중 비활성 존재 |
| 장비 | Relics | 유물 구매 가능 && **최저비용 항목이 장비** |
| 각인 | Relics | 유물 구매 가능 && **최저비용 항목이 각인** |

**유물 탭은 동시에 켜지지 않는다.** 최저비용 하나만 켠다.

- 규칙은 **가격을 상수로 박지 않는다** — 런타임에 `EquipCosts[tier]`와
  `SigilCost`를 읽어 비교한다. 그래서 **negotiation entry 6(각인 12유물 미서명)의
  영향을 받지 않는다**: 가격이 바뀌어도 규칙이 스스로 답을 낸다.
  PM 판정 그대로 — "72" 같은 임계를 상수로 박으면 판정이 뒤집힌다. 박지 않는다.
- 오도 실측: T0/T0/T0 + 유물 12에서 현행 "살 수 있음" 의미론은 `|12−2| = 10`
  (밴드 5배 위반). 최저비용 우선 규칙은 장비(2)를 가리켜 **오도 0**.

### 5.2 각인 컨텍스트 (N11 — G8 최강 후보)

각인 5종은 전부 12유물 동일가인데 기믹 도달률이 **9배** 벌어진다
(점화인 9/9 100% ↔ 집행인 1/9 11%). 가격은 이 차이를 말할 수 없다.

각인 행에 한 단어를 붙인다:

| 상태 | 라벨 | 색 |
|---|---|---|
| 바인딩 기믹이 다음 재판에 존재 | `다음 재판 대상` | 골드 |
| 존재하지 않음 | `휴면` | InkDim |
| 다음 재판 없음(전부 클리어) | `대기` | InkDim |

판정 출처는 **해당 스테이지의 실효 해저드 표**다 —
`HazardOverride ?? CampaignStages` 앵커. 뷰가 규칙을 복제하지 않는다.

이것이 G8 최강인 이유: 장르 0/17은 **회피가 아니라 불가능**이었다. 17타이틀
전부 메타 업그레이드가 전역 상수라 "다음에 유효한가"라는 질문 자체가 성립하지
않는다. 우리 각인은 기믹 바인딩이라 질문이 실재한다.

**금지선 준수**: 이 라벨은 `사라`고 말하지 않는다. `이건 다음 재판에 걸린다`고만
말한다. DD2 함정을 피하는 지점이 정확히 여기다.

조치 (이 사이클):
1. `tools/gen_hud_font.sh` 재실행 → `·` 포함
2. `FontCoverageTests`의 수집 규칙을 **생성기와 동일**하게 확장 —
   테스트가 생성기보다 좁으면 그 차집합은 영원히 사각이다

| 터치 래칫 | 헤더 4개 신규. **179.6 × 21.5 CSS px** — 높이는 탭과 동일 등급, 폭은 로비 최광. **새 위반 등급 아님**. 협상 기록 필수 |
| 대비 | 사유 라벨 `ignoreParentGroups` + InkDim = 8.69:1 |

### 왜 비대화형 헤더가 아닌가

접지 않는 라벨 헤더면 신규 컨트롤이 0개라 래칫이 안 변한다. 그러나 콘텐츠가
`1058 + 200 = 1258u`로 늘어 가시율이 **41.0% → 34.5%로 악화**된다. N1이 요구하는
것은 헤더가 아니라 **위치를 알 수 있는 상태**이므로, 접히지 않는 헤더는 축을
충족하지 못하면서 비용만 낸다. **접는 헤더는 래칫 비용을 내고 축을 산다.**
