# Gimmick Retune Spec v2 (최종) — cycle 2 Stage 2

트리거: 사용자 플레이테스트 "기믹이 안 보인다"(qa/discovery-notes.md).
**근본 원인은 배치 기하**: 세 기믹 전부 전투가 실제로 벌어지는 중심
(768,604) — 스폰·추적 수렴점 — 에 닿지 않았다. 벽 최대 x=608(중심 −160),
해류 밴드 간극이 정확히 스폰 y, 파일런 오라(220)가 스폰에서 252-255로 아슬
하게 밖. **회피가 위치 이동을 강제해야 기믹이 존재한다.**

원칙 유지: 고정 시간표(무RNG) · 텔레그래프 하한 · 단일 히트 ≤30% maxHP ·
양벽 동시 함정 금지. 미출시 콘텐츠 전용 — 기존 6스테이지 불변.

  최악 동시 2 (≤3 PASS).
