## §W. 웨이브 등장 알림 (즉시 가능, View 전용)

- `WaveStarted` 시: 스폰 포인트에 0.6s 경고 링(기존 스코치 문법) + 배너 펀치인(cycle2 A2 기존) + 카메라 미세 셰이크(0.05/0.15).
- 보스 웨이브는 링 색 적색 + 셰이크 0.35 (기존 BossSpawned 티어 재사용).
- **비용 S** — 기존 풀·이벤트만 사용.

## §K. 스킬 3단계 연출 (View, 부분 존재)

현행: 시전 순간 버스트 + 지속 링(펄스만). 3단계로 승격:

| 단계 | 내용 | 현행 |
|---|---|---|
| 예고(telegraph) | 시전 전 0.25s 지면 범위 링 — "여기 터진다" | **없음** |
| 시전(cast) | 수렴 글로우 → 방출 (V1 스펙 기존) | 부분 |
| 종료(resolve) | 소멸 링 축소 + 잔광 페이드 | 없음 |

- **제약**: 예고 단계는 심의 시전 타이밍보다 **앞설 수 없다** — 심은 입력 즉시 판정한다. 따라서 예고는 "시전 직후 0.25s 동안 범위를 보여주고 그 뒤 임팩트"로 구현하거나, 심에 캐스트 딜레이를 넣어야 한다(→ §S7).
- **K3 메시 색상 영향**: 스킬 피격 적의 `_block` 틴트를 원소색으로 0.4s(볼트=보라/파동=녹/노바=엠버/에이기스=시안). P2 랭크 글로우 문법 재사용, 우선순위는 피격 플래시 > 원소 틴트 > 랭크 글로우.
- **K4 셰이크 티어**: 기존 Nova 0.2/0.06 · Phase2 0.3/0.09 유지, 보스 스킬용 0.45/0.12 신설(§S8 종속).

## §M. 모션 자산 (Blender + 리타겟 파이프라인)

현행 액션 11종(`idle move run hit bighit attack critical avoid defence die show`). 요구 대비 결손:

| 신규 클립 | 용도 | 비고 |
|---|---|---|
| `attack2`, `attack3` | 콤보 2/3타 차별 모션 (#9) | 현행은 attack 1종 재생 |
| `cast_loading` | 스킬 시전 로딩 (#4) | 0.3s 루프 |
| `recoil` | 반동 (#3) | hit과 별개 — 공격자 측 |
| `knockdown` | 넉백 큰 반응 (#15) | bighit 확장 |

- 생성: `blender -b -P tools/blender/<script>.py` + mixamo 표준 스켈레톤 리타겟 (CLAUDE.md §3). 조인트 게이트(RUNTIME_ANIMATION_CONTRACT §3) 필수.
- `CinderActor.controller`에 스테이트 추가 — `ActorAction` enum 확장은 **심 계약**(SimTypes FROZEN)이므로 View 전용 서브스테이트로 처리하거나 §S6 개정.

## §C. 전환 시네마틱 (View + 자산)

- 기존: PrologueReveal 2.2s 스윕, 보스 인트로 레터박스+포커스 풀.
- 신규: 스테이지 전환(Ember Rest → 다음 방) 3s 컷신 — 카메라 궤도 + 스토리 자막 + 페이드. `CameraRig`에 `Profile.Cutscene` 추가, 입력 비차단(스킵 가능).
- 자산: 컷신 배경 키아트 6종(스테이지별) — `gti --dry-run` 선행, `docs/provenance/` 기록.

## §B. 3-5분 플레이타임 + 해금 해방감

- 현행 실측: 파일럿 클리어 cinder-span t=2700틱(45s) — **목표 대비 짧다**. 웨이브 수/적 HP는 frozen이므로 조정은 스테이지 구성(§T3 6스테이지 체인 = 5회 Ember Rest)으로 달성 — 이미 설계됨.
- 해금 연출: 랭크업/스킬 습득 시 **제스처 모션**(`show` 액션 재사용) + 골드 플래시(P2 FlashEquip 기존) + 아이템 외형 변화(P 레인 본 소켓).

### S8 설계 스케치 (승인 시 착수)

```
BossPhase { Index, HpThreshold, MoveMul, AttackSpeedMul, RangeMul, CooldownMul, Pattern[] }
```
- 페이즈 진입: `HP <= threshold` (사용자 요구: 체력 기준) — 현행 50% 1회를 75/50/25% 3회로.
- **수치 합 체감**: 각 페이즈의 (이속+공속+범위+쿨감) 합이 **증가**하되 개별 항목은 트레이드오프(예: P2 이속↑ 범위↓). 사용자 문구 "합이 작아지는"은 쿨타임 **감소**를 의미하는 것으로 해석 — 승인 시 확인 필요.
- 패턴 6종은 각각 텔레그래프(예고 링) → 시전 → 판정 → 회복 4구간. 전부 결정론(모듈러/카운터, RNG 금지).
- 자산 동반: 보스 스킬 모션 6종 + VFX 6종. **자산이 병목** — 패턴 2종(광역·지면)부터 착수 권고.
