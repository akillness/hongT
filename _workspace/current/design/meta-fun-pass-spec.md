# Meta Fun Pass v1.3 — 강화·메타 진행의 게임화 (cycle-2 Stage 2c)

요청: "강화쪽이랑 전체적으로 게임스럽게, 조사 기준으로".
서베이 근거 (trend-survey + benchmark-notes 램프 관례):
1. **구체 수치의 권능감** — Dead Cells/HoT 문법: "+3%"가 아니라 "공격력
   58 → 75.4"를 보여줄 때 성장이 체감된다.
2. **멀티플라이어 사다리** (benchmark 밴드: D3 GR/토먼트, Hades 계약) —
   클리어한 콘텐츠의 재도전 루프는 "같은 텔레그래프 문법 + 순수 배수"로
   만든다. 현재 클리어 스테이지는 재방문 동기 0 (실측: 유물 수급 외 무의미).
3. **리스크는 옵트인** — 강제 상향(D4 반감)이 아니라 선택형(Hades 열기).

제약: **심 무변경** — SIM_SPEC_HACKSLASH §5/§6 수치(스탯 +3%/+8HP/+2%,
장비 +6%/+8%/+8HP, 비용 [2,4,7,11,16])는 FROZEN 유지. 전부 뷰 레인:
표시(1·2·4) + HazardOverride 시임(3) + 뷰 보상 지급(3).

## M1. 성장 탭 — 파생 실수치 + 다음 포인트 미리보기

- 각 스탯 행에 **실효 수치** 표기 (심과 동일 공식·동일 상수 미러):
  공격 `58×(1+0.03a)×(1+0.06w)` → "공격력 75.4", 체력 `100+8v+8c` →
  "최대 체력 180", 이속 `218×(1+0.02s)` → "이동 262".
- `+` 버튼 옆 **다음 포인트 델타**: "+2.2 공격력" 식. 캡(10) 도달 시 "숙련".
- 하단 요약줄: "워든 전투력" 없이(허수 지표 금지) 3수치 나열만 — 정직 표기.

## M2. 장비 탭 — 티어 서사 + 강화 델타

- 티어명(worldview 법정 어휘, T0-T5): 무기 잿날→담금날→**판결인(T5)**,
  랜턴 香유→…→**증언등**, 망토 잿천→…→**집행포** (뷰 상수 테이블).
- 강화 버튼에 **효과 델타**: "유물 7 → 공격력 +4.2" (실수치).
- 현재 랭크 효과 실수치 병기: "무기 T3 — 공격 +18%".

## M3. 심판 서약 (Verdict Pact) — 재도전 멀티플라이어 사다리

- **클리어한 스테이지 한정** 카드에 서약 토글 노출: "서약 강하" (기본 off).
- 서약 ON: 해당 스테이지의 서약 해저드 테이블(기존 오버라이드에 기믹 추가
  — 스테이지 정체성 기믹의 강화 배치)로 출정 + 클리어 시 **유물 2배**
  (뷰 지급 — sim.Relics×2, GameDirector).
- 서약 테이블(각 스테이지 정체성 기믹을 +1 강화 — 신규 종류 없음):
  각 스테이지 기존 배치 + 정체성 기믹 1-2기 추가. 텔레그래프 예산(≤3,
  동종 ≤2) LCM 센서스 필수 — 테이블은 구현 레인이 예산 검증 후 확정,
  위반 시 위상 조정.
- 진행도 영향 없음: 서약은 세이브 미기록(출정별 선택), 첫클리어 보너스와
  비중복(이미 클리어한 스테이지 전용이므로 자연 배제).
- 결정론 유지: 서약 = 다른 고정 배치 테이블일 뿐(무RNG).

## M4. 군단 탭 — 동료 정체성

- 로스터 그리드에 동료 별칭 1줄(스테이지 별칭 문법): ember-cohort "잿불
  사도", shade-echo "그림자 메아리", scout-echo "정찰꾼 메아리" 등 —
  기존 CompanionNameFor 어휘 재사용 + 설명 짧게.

## 경제 서명 (G5 — negotiation entry 5)

- designer: 서약 2배는 "더 어려운 고정 배치의 정당 보상, 첫클리어 보너스
  비중복이라 인플레 제한적".
- PM: T5 도달 세션 밴드(10-20) 하한 침식 우려 → 서약 해금이 "해당 스테이지
  클리어 후"라 초반 가속 없음, 승인. 실측 재검증: 서약 런 평균 유물이
  일반 런의 ≤2.2×인지 QA 확인.
- agreed: **서약 클리어 유물 ×2, 첫클리어 보너스와 비중복, 세이브 미기록**.

## 검증

- EditMode: 서약 테이블 센서스(예산), 카탈로그 계약, 델타 수식 미러 테스트
  (뷰 공식 == 심 공식 — 상수 참조로 자동 동기, 리터럴 금지).
- 골든: 서약 미선택 경로 불변(기존 골든 그대로). 서약 경로는 신규 golden
  불요(뷰 데이터 — 단 서약 테이블 자체는 카탈로그 테스트로 고정).
- 브라우저: 성장 탭 수치 표기 + 서약 토글 + 서약 런 유물 2배 육안.

## 세이브 스키마 영향 — **없음 (의도적 결정)**

v1.3이 세이브에 새로 넣는 필드는 **0개**다:
- 서약 토글 = 세션 한정 뷰 상태(Dictionary, 미저장). 출정마다 다시 켠다 —
  Hades 열기 계약과 동일한 옵트인 문법이고, 전방 호환 리스크(구 빌드가
  모르는 필드를 Save()로 소실)를 원천 차단한다.
- 유물 ×2는 지급 시점 계산 — 기존 relics 필드로 흐른다.
- 티어명/실수치/별칭 = 순수 표시.
스키마 버전 필드 도입은 **실제로 영구 필드가 필요해지는 사이클**로 연기
(그때 신규 키 분리안 우선 검토 — CampaignStore 파서는 전방 호환이 없다).
