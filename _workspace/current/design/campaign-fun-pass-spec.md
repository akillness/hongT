# Campaign Fun Pass — 전 9스테이지 기계적 정체성 (cycle-2 Stage 2b)

요청: "전체 스테이지를 조사 기준으로 더 게임스럽게". 서베이 근거 2개를
캠페인 전체에 적용한다:
1. **스테이지 정체성 = 지배 기믹 1개** — 기존 6스테이지는 기믹 종류 구분이
   없는 지리 리믹스였다(설계 분석 §6 리스크 1의 잔여).
2. **장르 램프 관례** (벤치마크 밴드 4): 스테이지 N에서 기믹 1종 도입 →
   N+1에서 리믹스. Dead Cells/Hades 바이옴 문법 = **예고(preview) → 숙달
   (mastery)** 아크.

구현 원칙: **데이터 전용** — 신규 기믹 종류 없음, 기존 6종(vent/pillar/
altar/current/pylon/wall)의 배치·위상 문법만. 심 앵커 테이블은 ash-march
1건만 수정(피날레 수렴), 나머지는 전부 StageCatalog HazardOverride(뷰 데이터).
아레나·프롤로그 불변.

## 9스테이지 아크 — "집행 기믹의 계보"

| # | 스테이지 | 정체성(카드 표기) | 배치 | 변경 |
|---|---|---|---|---|

램프 읽기: vent(0도입→1숙달) → pillar(2) → altar(3) → current(4예고→6숙달)
→ pylon(5예고→7숙달) → wall+전부(8). 모든 기믹이 숙달 전에 안전한 예고
스테이지를 가진다 — "학습 가능한 안무" 정체성의 캠페인 버전.

- 동시 텔레그래프 사전 산술: gallery 동종 최대 2(0.6s 간격 링, tel 0.8s) ·
  well 1 · throne 2(조류 tel×vent2 겹침 [0.4,0.5)) · verdict 1 · march 2 —
  전부 예산(≤3, 동종 ≤2) 내. LCM 센서스 테스트로 고정.
- ash-verdict pylon: 오라 280이 중앙 제단을 덮음 — 제단 채널 중 접근 적이
  실드를 받는 긴장. 선파괴 학습 의도.
