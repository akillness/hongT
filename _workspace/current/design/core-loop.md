# Core Loop — cycle 2 (G7 수치 모델)

기존 인런 루프(전투→웨이브→픽업→레벨→보스)는 cycle-1에서 G7 PASS 이력.
cycle 2는 **기믹 상호작용 루프**를 신설 스테이지별로 추가 정의한다.

## Loop N1 — cinder-sluice "해류 리듬" (tide-current)
- 주기: 6.0 s (해저드 주기와 동일) — 대역 30–180 s는 상위 웨이브 루프
  (스폰→해류 활용 진형 붕괴→섬멸→픽업, 실측 목표 25–40 s)로 충족.
- 액션/루프 ≥3: ① 텔레그래프 확인 ② 레인 횡단/역주행 결정 ③ 적 유인
  ④ 밀린 적 처치.
- 보상 이벤트 ≥1: 처치 픽업(기존) + 진형 붕괴로 인한 다중 처치(점수).

## Loop N2 — ember-bastion "선파괴 우선순위" (ember-pylon)
- 주기: 파일런 1기 교전 사이클 실측 목표 30–60 s (접근→pillar 차폐 돌파→
  파일런 파괴→실드 해제된 적 섬멸).
- 액션 ≥3: ① 오라 범위 파악 ② 접근로 선택 ③ 파일런 타격(콤보/스킬 배분)
  ④ 잔적 처리. 보상: PylonDown 이벤트 + TTK 정상화(체감 보상) + 픽업.

## Loop N3 — ash-march "행진 리듬" (ash-wall)
- 주기: 22.5 s 고정 사이클 — 대역 내.
- 액션 ≥3: ① rest 중 좌측 픽업 회수 ② telegraph에 우측 이탈 ③ 적을 벽으로
  유인 ④ altar(우측) 체류 보상 판단.
- 보상 ≥1: 벽 처치 크레딧(점수/기름) + AltarBlessing(+18 기름).

# Core Loop — cycle 9 (G7 재모델링, run-id 20260809-dungeon-fun-authorship)

cycle-1이 인런 루프를, cycle-2가 기믹 루프를 모델링했다. 둘 다 **전투 루프**다.
이 절은 그 위에 **저작 루프(authorship loop)**를 신설한다.

근거: `.survey/dungeon-entry-fun-factors/solutions.md` Key Insight —
재미는 *플레이어가 다음 30초의 위험을 결정하고, 그 결정이 사전 공표된 명료한
조건 위에서 이루어질 때* 생긴다.

## 왜 기존 G7 모델이 통과했는데도 재미가 없었는가

cycle-1·2의 G7 판정은 정직했다. 주기 30–180초 · 액션 ≥3 · 보상 이벤트 ≥1 —
세 조건 전부 실측으로 만족한다. 그런데 사용자는 재미없다고 보고했다.

**모델이 측정하지 않은 항목이 있다: 그 루프 안에서 플레이어가 무엇을
저작하는가.** 액션 수는 "무엇을 하는가"를 세고, 저작은 "무엇을 정하는가"를
센다. 우리 루프는 전자가 풍부하고 후자가 0이었다.

§4m의 형태다 — **테스트가 정답과 오답을 구분할 수 없는 좌표계에서 재면
통과는 의미가 없다.** 액션 수만 세는 G7 모델은 "슬라이더 3개짜리 게임"과
"저작 가능한 게임"을 구분하지 못한다.

## Loop A1 — 저작 루프 (신설, G7 주 모델)

```
영장(서약 선언) → 런 진입 → [현장 각인 드래프트] × N → 스테이지 클리어
  → 판결 등급 채점 → 다음 영장의 근거
```

| 항목 | 값 | 근거 |
|---|---|---|
| 주기 | 스테이지 1회 = **미측정** (QA T9) | 밴드 4–8분 권고 |
| 저작 결정/루프 | **6–9** (서약 1 + 현장 각인 5–8) | QA 밴드 4–9, 하한 3 |
| 첫 결정까지 | **0초** (문턱) | 밴드: 문턱 0초 / 인런 ≤45초 |
| 보상 이벤트/루프 | 등급 1 + 배수 1 + 기존 픽업/레벨업 | — |
| **선택 압력** | **0.00 → 진행 밴드(초반 ≥0.70 · 중반 ≥0.80 · 후반 ≥0.85)** | 신설 지표, §아래. 초안 ≥0.75는 9/9 반증됨 |

### 신설 지표 — 선택 압력

`선택압력 = 1 − (제시 수 / 풀 크기)`

G7 모델이 "결정이 있는가"만 묻고 "그 결정에 실질이 있는가"를 묻지 않았기
때문에 신설한다. 제시 3 / 풀 3이면 압력 0이고, 그것은 결정이 아니라 슬라이더다.

분야 대조: VS ~0.97(3–4 제시 / 100+ 풀) · HoT 가변(풀이 런 중 증가) ·
**우리 현재 0.00**. 그리고 Hades는 **선택지를 줄이는 것 자체를 난이도
조건으로 판다**(Approval Process, 랭크당 −1, 2/3 Heat) — 이 분야는 선택 폭을
화폐로 취급한다.

**G7 판정에 이 지표를 포함시킨다.** 압력 <0.5인 결정창은 결정으로 세지 않는다.

## Loop A2 — 온사이트 루프 (미클리어 스테이지 한정)

```
예고 목록 봉인 → 미지의 시간표를 실전에서 읽음 → 클리어 → 그 스테이지의
  봉인 가치 영구 소멸 → 다음 미클리어 스테이지로 이월
```

- 주기: 스테이지 1회, **1회성**. 클라이밍 온사이트와 동일 — 루트당 한 번.
- 이 루프는 **진행도와 함께 소진된다.** 9스테이지를 다 깨면 A2는 닫히고
  A1(심판 서약)만 남는다. 의도된 설계다: 온사이트는 초반 플레이어의 루프이고,
  심판 서약은 후반 플레이어의 루프다. **둘의 합집합이 전 진행도를 덮는다.**
- 조사가 지목한 최대 공백("첫 입장을 재미있게 만드는 타이틀이 없다 — 강력한
  문턱 메커니즘이 전부 클리어 이후 해금")을 정면으로 겨눈다.

## 기존 루프와의 관계

| 루프 | 층위 | 상태 |
|---|---|---|
| 인런 전투 (cycle-1) | 초 단위 | **무변경** |
| 기믹 상호작용 N1–N3 (cycle-2) | 6–22.5초 | **무변경** |
| **저작 A1 (cycle-9)** | 스테이지 1회 | **신설 — G7 주 모델** |
| **온사이트 A2 (cycle-9)** | 스테이지 1회, 1회성 | **신설** |
| 메타 (클리어→포인트→장비/각인) | 세션 간 | 무변경 |

A1은 기존 루프를 **대체하지 않고 감싼다.** 전투 루프는 그대로 돌고, 그 위에
"이번 판은 내가 이렇게 정했다"는 층이 얹힌다.
