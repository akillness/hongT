## 정의

```
선택 압력 = 1 − (제시 수 / 풀 크기)
```

압력 0 = 풀이 제시 수와 같다 = 선택이 아니라 슬라이더.
목표 ≥0.75 = 제시 3일 때 풀 ≥12.

## 입력 (전부 코드 직독)

**제시 수 3** — `CinderSim.BuildPreparationOffer` 선례(Ember Rest 3장)와
설계서 §4.2 표기.

**풀 = 스탯 3 + 스테이지 유효 각인 면**

- 스탯 3종: 공격/생명/민첩 (`GrowthChoiceKind`)
- 각인 5종 × A/B면 = 10면, **스테이지 해저드로 필터링**(설계서 §4.4)

| 각인 | 바인딩 기믹 | 심 훅 |
|---|---|---|
| 역류인 | 해류 | `_sigilCurrentPlayerPushMult` |
| 판결인 | 방벽주 | `PylonAuraMultiplier` / `StrikePylons` |
| 집행인 | 장벽 | `_sigilWallEnemyTick` |
| 점화인 | 분출구 | `_sigilVentEnemyDamage` |
| 증언인 | 제단 | `_sigilAltarHoldSeconds` |

기둥(ObsidianPillar)에는 각인이 없다 — 풀에 기여하지 않는다.

## QA 권고

**목표치를 고치거나 구조를 고쳐야 하고, 둘 중 무엇인지는 designer 결정이다.**
QA는 셋 다 계산해 두었다:

1. **목표를 스테이지 진행에 따라 밴드로 정의한다** — 예: 초반 ≥0.55 /
   중반 ≥0.70 / 후반 ≥0.80. A3+B5가 이 밴드를 만족한다(0.727/0.823/0.897).
   단 **초반이 가장 낮다는 구조는 그대로 남는다.**
2. **필터를 부분 해제한다** — 미바인딩 각인을 낮은 크기로만 허용.
   상황 의존성을 약화하되 없애지는 않는다. 계산 필요(레버 C의 변형).
3. **초반 스테이지에 기믹 종류를 늘린다** — 데이터 변경이지만 **G2 무변경
   목표와 충돌**하고 예고 예산 재센서스가 붙는다.

**QA가 하지 않는 것**: 어느 레버를 쓸지 고르는 것. 이 문서는 숫자만 소유한다.

## §4r 준수 기록

이 센서스는 **임계값(0.75)이 이미 문서에 있고 그것을 재는 조건이 없던**
상태에서 실행됐다. 조건을 명명했다:

- 제시 수 = 3 (Ember Rest 선례 + 설계서 표기)
- 풀 = 스탯 3 + 스테이지 해저드로 필터링된 각인 면
- 유효 해저드 표 = `HazardOverride ?? anchor` (서약 테이블 제외)

**이 세 조건이 바뀌면 이 표의 모든 값이 바뀐다.** 조건 없는 압력 수치는
인용 금지.
