지우고 분류를 상수 옆으로 옮겨서, 다음 보스는 분류를 빠뜨릴 수 없다.

## 눈에 안 보이지만 중요한 변화

- **서약 유물 ×2가 이제 테스트로 고정된다.** 코드 주석은 "EditMode 경제
  테스트가 고정한다"고 적혀 있었지만 그 테스트는 없었고, 근거는 스크린샷
  1장뿐이었다. 실제 로비 토글을 눌러 출정하는 테스트를 붙였고, 협상
  entry 5의 미해결 QA 조건이 측정으로 충족됐다: **일반 3유물 → 서약 6유물
  = 2.00×** (밴드 ≤2.2×). 게이트 실행마다 재측정된다.
- **빌드 경고 2 → 0.** 죽은 필드 1쌍 삭제, 폐기 API 5곳 교체.
