# 1. 게임 제목 및 한 줄 소개

**Abyssal Lantern — Hold the Cinder Court** (한글 표기: 심연의 등불 — 재의 법정을 사수하라)

> 마지막 등불을 든 **황혼의 파수꾼(Dusk Warden)** 이 되어, 재로 뒤덮인 법정을
> 아홉 구역에 걸쳐 정화하는 **쿼터뷰 핵앤슬래시 액션 게임**입니다.

브라우저 주소 하나로 바로 실행됩니다. 설치·로그인·계정·별도 라이선스가 필요
없습니다. Unity 6000.5.6f1 / URP / WebGL로 만든 3D 빌드이며, 진행도는
플레이어 브라우저 안(localStorage)에만 저장되고 서버로 아무것도 보내지
않습니다.

한 줄 더 풀어 쓰면 이렇습니다. **등불의 기름은 하나뿐인데 쓸 곳은 네 개고,
때리는 것과 살아남는 것이 같은 자원을 두고 다툽니다.**

## 1.1 이 게임이 다른 점

| 특징 | 내용 |
|---|---|
| 무작위 없는 액션 | 전투 계산에 난수를 전혀 쓰지 않습니다. 같은 입력은 언제나 같은 결과를 냅니다. 운이 아니라 읽기와 타이밍만이 실력입니다. |
| 명령을 "말로" 내리는 전투 | `Enter`로 콘솔을 열고 한국어 문장("결계 쳐", "집중공격")을 입력하면 즉시 스킬·동료 명령으로 실행됩니다. |
| 기세(모멘텀) | 붙어서 계속 때리면 근접 피해가 최대 1.30배까지 오르고, 맞거나 물러나면 깎입니다. |
| 동료 3인 동행 | 적 정예를 처치해 "추출"하면 동료가 되고, 각자 고유 특기를 스스로 씁니다. |

# 2. 게임 방법

## 2.1 목표

플레이어는 **황혼의 파수꾼** 한 명을 조작합니다. 목표는 모드마다 다릅니다.

| 모드 | 목표 | 진입 |
|---|---|---|
| **점화 훈련 (프롤로그)** | 옆에서 비스듬히 잡은 2.5D 시점에서 3웨이브(4·6·8기)를 정리하며 이동·타격·기름을 익힙니다. 클리어해야 캠페인이 열립니다. | 로비 첫 진입 시 안내 |
| **캠페인 (본편)** | 아홉 구역을 순서대로 정화합니다. 각 구역은 웨이브를 밀어낸 뒤 **보스를 처치**하면 클리어입니다. | 로비 → 출정 |
| **훈련장** | 적 없이 기믹만 도는 60초 시련 5종 × 3등급. 죽지 않고 패턴만 외우는 연습장입니다. | 로비 → 성소 (프롤로그 클리어 후 개방) |
| **아레나** | 끝없이 밀려오는 적을 상대로 웨이브를 최대한 깊게 미는 무한 모드. | `?mode=arena` 링크 |

**캠페인 9구역 (3막 구성)**

| # | 구역 | 보스 | 배우는 것 |
|---|---|---|---|
| 1 | 재의 다리 (Cinder Span) | Cinder Warden | 분출구 입문 |
| 2 | 불씨 회랑 (Ember Gallery) | Cinder Warden | 불씨 윤무 |
| 3 | 서약의 성당 (Abyss Chancel) | Veil Tactician | 흑요석 미로 |
| 4 | 증언의 우물 (Witness Well) | Veil Tactician | 쌍 제단 |
| 5 | 메아리 왕좌 (Echo Throne) | Gate Sovereign | 왕좌의 조류 |
| 6 | 재의 판결 (Ash Verdict) | Gate Sovereign | 판결의 방벽 |
| 7 | 재의 수문 (Cinder Sluice) | Sluice Keeper | 해류 숙달 |
| 8 | 불씨 요새 (Ember Bastion) | Bastion Sentinel | 방벽 숙달 |
| 9 | 재의 행진 (Ash March) | Ash Magistrate | 집행 수렴 |

앞 구역을 클리어해야 다음 구역이 열립니다. 로비 카드에는 잠긴 이유(점화 훈련
필요 / 선행 구역 미클리어)가 항상 문장으로 적혀 있어, 무엇을 해야 열리는지
헤맬 일이 없습니다.

## 2.2 핵심 자원 — 등불 기름

기름은 최대 100이고 **초당 7씩** 자동으로 차오르며 **적을 처치할 때마다 6**이
추가로 들어옵니다. 네 개의 스킬과 대시가 전부 이 기름을 씁니다(대시 8, 화살
25, 파동 30, 방패 30, 노바 45). 그래서 "지금 태울 것인가, 다음 위기를 위해
남길 것인가"가 매 순간의 판단입니다.

## 2.3 조작

### 키보드 — 캠페인 / 훈련장

| 입력 | 동작 |
|---|---|
| `W` `A` `S` `D` 또는 방향키 | 이동 |
| `Space` | 기본 공격. 누르고 있으면 3타 콤보(58 / 58 / 87 피해, 3타는 넉백)가 자동으로 이어집니다 |
| `Space` 길게 누르기 | 3타를 마친 뒤에도 계속 누르면 **차지**(0.45초 충전 → 피해 1.8배 · 넉백 2배). 덜 찬 상태에서 떼면 아무 일도 없습니다 |
| `Shift` | 질주(대시) — 190px, 0.22초, **전 구간 무적**, 쿨 1.6초, 기름 8 |
| `Q` | 균열 화살 — 420px 내 최근접 적에게 145 피해 + 반경 115 스플래시 (쿨 6.5초, 기름 25) |
| `E` | 묘지 파동 — 발밑에 반경 190 장판을 3초간 깔고 0.5초마다 26 피해 (쿨 4초, 기름 30) |
| `R` | 잿불 노바 — 반경 230 전방위 폭발, 110 피해 + 넉백 (쿨 8초, 기름 45) |
| `F` | 공허 방패 — 40 피해를 흡수하는 실드 8초 + 시전 무적 0.2초 (쿨 12초, 기름 30) |
| `G` | 동료 정지 — 그 자리를 사수 |
| `H` | 동료 복귀 — 내 곁으로 |
| `V` | 동료 고유 특기 발동 (준비된 동료 전원) |
| `1` `2` `3` | 레벨업 성장 선택 — 공격 / 생명 / 민첩 |
| `Enter` | 명령 콘솔 열기 / 입력 확정 |
| `Esc` | 명령 콘솔 취소 |
| `정보` 버튼 | 지금까지 본 안내를 다시 읽는 코덱스 |

### 키보드 — 아레나 / 프롤로그

아레나와 프롤로그는 원작 규칙을 그대로 보존한 모드라 조작이 더 단순합니다.

| 입력 | 아레나 | 프롤로그 |
|---|---|---|
| `W` `A` `S` `D` / 방향키 | 이동 | 이동 |
| `Space` | 기본 공격 (콤보 없음) | 기본 공격 |
| `Q` | 잿불 노바 | — |
| `E` | 등불 결계 | — |
| `R` | 재시작 | 재시작 |

콤보·차지·대시·동료·명령 콘솔은 캠페인(던전) 전용입니다.

### 모바일 / 터치

터치 기기에서는 화면에 조작 UI가 자동으로 뜹니다.

- **왼쪽 아래**: 어디를 눌러도 그 지점에 생기는 **가상 조이스틱**(360° 이동)
- **오른쪽 아래**: `타격` 버튼(누르고 있으면 콤보·차지까지 동일하게 동작)
- **타격 위**: `질주` 버튼 (캠페인에서만 표시)
- **스킬 카드 4장과 동료 카드 3개**는 그대로 탭해서 발동합니다

터치 버튼은 가장 좁은 세로 화면(390 CSS px)에서도 44pt 이상을 확보하도록
배치되어 있습니다.

### 명령 콘솔 — 문장으로 싸우기

`Enter`를 누르면 화면 아래에 입력창이 열립니다. 한국어를 그대로 치면 됩니다.

| 입력 예 | 결과 |
|---|---|
| `결계`, `방패`, `실드` | 공허 방패 시전 |
| `노바`, `폭발` | 잿불 노바 시전 |
| `파동`, `펄스` | 묘지 파동 시전 |
| `화살`, `볼트` | 균열 화살 시전 |
| `질주`, `대시`, `돌진` | 질주 |
| `집중공격`, `싸워`, `잡아` | 동료가 근처 표적을 추격·교전 |
| `방어`, `지켜`, `대기` | 동료가 현재 지점을 사수 |
| `복귀`, `이리와`, `따라와` | 동료가 곁으로 복귀 |
| `특기`, `필살기`, `고유기` | 준비된 동료가 각자 고유 특기 발동 |

`노바 쓰고 결계 쳐`처럼 한 문장에 여러 명령을 적으면 **적힌 순서대로** 차례로
실행됩니다. 해석은 전부 게임 안에서 이뤄지므로 인터넷 연결이나 외부 서비스가
필요 없습니다. (별도로, 플레이어 본인의 Gemini API 키를 직접 입력하면
자유문장 해석을 보조받는 선택 기능도 있습니다. 키는 빌드에 포함되지 않으며
입력하지 않아도 위 표의 명령은 전부 동작합니다.)

## 2.4 전투를 이루는 것들

**사거리 비대칭.** 파수꾼의 사거리는 160, 잡졸의 사거리는 76입니다. 두 배 넘게
깁니다. 무작정 파고들면 포위당하고, 거리를 유지하며 치고 빠지면 한 대도 맞지
않고 정리할 수 있습니다. 이 게임의 기본기입니다.

**기세(모멘텀).** 근접 공격이 적에게 닿을 때마다 게이지가 9, 처치하면 14가 더
찹니다(최대 100). 1.6초 동안 아무것도 못 맞히면 초당 12씩 빠지고, **맞으면
한 번에 25가 날아갑니다.** 게이지 30 / 60 / 90에서 근접 피해가 각각 1.08배 /
1.18배 / 1.30배가 됩니다. 스킬 피해에는 적용되지 않습니다 — 붙어서 칼로
싸우는 쪽에만 주는 보상입니다.

**원소 상성.** `불씨 > 서리 > 장막 > 공허 > 불씨` 순환이며 유리하면 +20%,
불리하면 −15%입니다. 기본 공격·콤보는 무속성이고, **스킬에만** 적용됩니다.

**성장(런 안).** 처치로 경험치를 얻어 최대 12레벨까지 오릅니다. 레벨업마다
`1 공격(+8% 피해)` / `2 생명(+최대 HP 6, 즉시 회복)` / `3 민첩(+4% 이동 및
대시 쿨 −6%)` 중 하나를 5초 안에 고릅니다. **고르는 동안에도 전투는 멈추지
않고**, 무시하면 아무것도 추가되지 않습니다.

**정예와 추출.** 웨이브마다 최대 1기씩 금빛으로 빛나는 정예가 나옵니다
(HP 3배). 정예를 처치하면 10초간 시체가 남고, 그 반경 90px 안에서 **가만히
2초를 버티면** 추출이 완료됩니다. 움직이거나 맞으면 처음부터입니다. 처음
추출한 종류는 동료 명단에 등록되고 이번 런의 피해가 8% 늘어납니다. 이미 있는
종류면 유물 30을 대신 받습니다.

**동료 최대 3인.** 로비 "군단" 탭에서 최대 세 명을 편성합니다. 동료는 알아서
반경 300 안의 적을 물고 늘어지며(2초간 표적을 고정), 각자 하나씩 고유 특기를
갖습니다.

| 동료 | 특기 | 쿨 | 반경 | 피해(플레이어 대비) | 대상 |
|---|---|---|---|---|---|
| 정찰꾼 메아리 | 일제사격 (Volley) | 6.0초 | 240 | 0.55배 | 최대 3 |
| 그림자 메아리 | 저주 (Hex) | 8.0초 | 260 | 0.40배 | 최대 8 |
| 홀린 자 메아리 | 지진 (Quake) | 9.0초 | 170 | 0.70배 | 최대 6 (넉백 90) |
| 잿불 사도 | 섬광 (Flare) | 7.0초 | 200 | 1.10배 | 1 |

쿨이 돌아오고 사거리 안에 적이 둘 이상이면 알아서 씁니다. `V`(또는 콘솔
`특기`)로 즉시 쓰라고 명령할 수도 있습니다.

**돌발 상황.** 두 가지가 자동으로 열립니다. **위기** — 체력이 35% 아래로
처음 떨어질 때 3초(런당 2회, 50% 이상 회복해야 재무장). **기세** — 누적
처치가 12의 배수를 넘길 때 6초(웨이브당 1회). 이 창 자체는 아무 수치도 바꾸지
않고, 장착한 각인이 그 창에서만 발동하는 조항을 갖습니다.

**각인 5종.** 로비에서 유물 12로 해금하며 **두 칸만** 장착합니다. 각 각인은
`A면(견딘다)` / `B면(적에게 돌려준다)` 중 하나를 골라 씁니다. 면 전환은
무료·무제한입니다.

| 각인 | 대상 기믹 | A면 | B면 |
|---|---|---|---|
| 역류인 | 해류 | 내가 밀리는 힘 ×0.5 | 적이 밀리는 힘 ×1.5 |
| 판결인 | 방벽주 | 적 보호 오라 0.40 → 0.70 | 방벽주 파괴 피해 ×2 |
| 집행인 | 잿벽 | 내가 받는 틱 10 → 6 | 적이 받는 틱 10 → 18 |
| 점화인 | 분출구 | 맞으면 기름 +12 (피해는 그대로) | 분출구가 적에게도 14 피해 |
| 증언인 | 유물 제단 | 채널 1.2초 → 0.8초 | 기름 획득 +18 → +30 |

설계 규칙상 **완전 면역은 없습니다.** 어떤 각인을 껴도 기믹은 여전히 플레이어의
움직임을 바꿉니다.

**보스 4종 성향.** 보스는 잡졸의 **6배 체력**을 가진 다단 페이즈 전투이며,
구역마다 성향이 다릅니다.

| 성향 | 등장 구역 | 성격 |
|---|---|---|
| Warden | 1·2·8 | 2페이즈. 느리지만 사거리와 피해가 크고, 예고 동작이 가장 깁니다(0.25초) |
| Tactician | 3·4·7 | 3페이즈. 빠르고 예고가 가장 짧으며(0.083초), 후반에 호위 5기를 부릅니다 |
| Sovereign | 5·6 | 3페이즈. 균형형. 페이즈가 오를수록 예고가 짧아집니다 |
| Monarch | 9 | 최종. 2페이즈에서 호위 3기, 3페이즈에서 예고가 절반이 됩니다 |

모든 성향에서 페이즈가 오를수록 **예고는 짧아지고 이동·사거리·피해는 커집니다.**
보스가 체력을 잃어서 약해지는 일은 없습니다.

**전리품 등급.** 던전에서 떨어지는 모든 아이템에 등급이 붙습니다.

| 등급 | 표기 | 배율 | 체력 파편 | 기름 | 유물 |
|---|---|---|---|---|---|
| 일반 | (수식어 없음) | 1.00 | +18.0 | +35.0 | +250 |
| 정교한 | 청록 | 1.45 | +26.1 | +50.8 | +362 |
| 전설의 | 금색 | 2.10 | +37.8 | +73.5 | +525 |

등급도 난수가 아니라 (적 번호 · 웨이브 · 획득 순서)의 결정론적 해시로
정해집니다. 또한 **일반이 6번 연속 나올 수 없고, 전설이 아닌 것이 19번 연속
나올 수 없습니다.** 보스 드롭은 항상 전설입니다. 무엇을 주웠는지는 화면
왼쪽에 `정교한 잿불 파편 x2` 처럼 쌓이는 획득 팝업으로 알려주며, 등급은 글자
색과 함께 행 왼쪽 끝의 색 막대로도 표시되어 색 구분이 어려워도 읽힙니다.

**잿불 휴식 (Ember Rest).** 1~8구역을 클리어하면 결과창 대신 곧바로 휴식
화면이 뜹니다. 준비 효과 3개 중 하나를 고르거나 건너뜁니다. 효과는 **바로
다음 한 구역에만** 적용되고 저장되지 않습니다. 카드에는 "잿불 노바 피해 +20%"
처럼 대상과 정확한 수치가 그대로 적혀 있습니다.

**메타 성장 (로비).** 구역 클리어 +2포인트, 보스 첫 처치 +1포인트를 받아
`성장` 탭에서 공격(+3%/pt) · 체력(+8HP/pt) · 이속(+2%/pt)에 최대 10씩
배분합니다. 유물은 `장비` 탭에서 무기(+6%/티어) · 랜턴(기름 재생 +8%/티어) ·
망토(+8HP/티어)를 T5까지 올리는 데 씁니다(티어당 2·4·7·11·16 유물).

**난이도 4단계.** 출정 전에 고를 수 있습니다.

| 난이도 | 받는 피해 | 적 공격 속도 | 동시 공격 인원 | 그룹 AI |
|---|---|---|---|---|
| 입문 | 0.65배 | 0.82배 | 2명 | 꺼짐 |
| 보통 | 1.00배 | 1.00배 | 제한 없음 | 꺼짐 |
| 어려움 | 1.35배 | 1.19배 | 3명 | **켜짐** |
| 악몽 | 1.70배 | 1.43배 | 4명 | **켜짐** |

어려움 이상에서는 적이 한꺼번에 달려들지 않고, 차례를 받지 못한 적은 플레이어
주위 8슬롯 포위 링으로 물러나 대기합니다. 방금 휘두른 적은 차례를 잃고 뒤로
빠지므로 "치고 빠지고 다음이 들어오는" 교대가 생깁니다. 또 정면이 아닌 적에게
우선권이 가므로 **첫 타는 측면이나 등 뒤에서 들어옵니다.**

## 2.5 처음 하는 사람을 위한 안내

새 기믹이나 새 상황을 처음 만나면 게임이 스스로 설명합니다. 안내는 총 23종이며,
반드시 알아야 하는 8종(기믹 6 + 승패 2)은 **화면을 잠깐 멈추고** 보여주고,
나머지 15종은 플레이를 끊지 않는 토스트로 지나갑니다. 각 안내는 한 번만
뜨고, 이후에는 `정보` 버튼으로 언제든 다시 읽을 수 있습니다.

## 2.6 종료 조건

런은 정확히 두 가지 방식으로 끝납니다.

**1) 패배 — 체력이 0이 됨.**
결과 오버레이가 뜨고 점수·처치 수·획득 요약을 보여줍니다. `다시 도전`으로
같은 구역을 재시작하거나 로비로 돌아갑니다. 재도전해도 잿불 휴식 효과는
따라오지 않습니다.

**2) 승리 — 구역 보스 처치.**
보스를 쓰러뜨리면 남은 잡졸이 흩어지며 클리어로 처리됩니다.
- **1~8구역**: 결과창을 건너뛰고 곧바로 **잿불 휴식**으로 이어집니다. 여기서
  준비 효과를 고르면 다음 구역으로 계속 진행합니다.
- **9구역(재의 행진)**: 잿불 휴식 없이 **최종 결과 오버레이**를 표시합니다.
  캠페인 완주입니다. 로비로 돌아가는 것은 플레이어가 이 화면에서 직접 선택할
  때만 일어납니다.

그 밖에:
- **아레나**는 체력이 0이 될 때까지 계속됩니다. `R`로 즉시 재시작합니다.
- **프롤로그**는 3웨이브를 비우면 카메라가 쿼터뷰로 열리는 연출과 함께 로비로
  돌아가고, 이때 캠페인과 훈련장이 해금됩니다.
- **훈련장 시련**은 60초가 지나면 종료됩니다. 적이 없으므로 죽지 않고, 처치·
  유물 같은 경제 보상도 없습니다(5종 전부를 최고 등급으로 완주하면 일회성
  유물 +2).
- 전투 중 언제든 `포기` 버튼으로 런을 중단하고 로비로 돌아갈 수 있습니다
  (확인 창을 한 번 거칩니다).

진행도·장비·메타 성장·각인 해금은 브라우저 localStorage에 저장됩니다. 잿불
휴식 선택과 기세 게이지는 저장되지 않습니다.

## 3.2 소스에서 직접 빌드

심사 과정에서 소스를 직접 빌드해 확인하려면 아래와 같이 합니다.
**Unity 6000.5.6f1 (WebGL 모듈 포함)** 이 필요합니다.

```bash
git clone https://github.com/akillness/hongT.git
cd hongT
git lfs pull                     # FBX·폰트 실체 파일 내려받기 (필수)

# 캐릭터 임포트 → 씬 생성 → WebGL 빌드
bash tools/unity_batch.sh method CinderCourt.EditorTools.CharacterImportPipeline.ImportAll
bash tools/unity_batch.sh method CinderCourt.EditorTools.SceneBuilder.Build
bash tools/unity_batch.sh build          # build-webgl/ 생성

# 로컬 서버로 열기 (file:// 로는 WebGL이 실행되지 않습니다)
cd build-webgl && python3 -m http.server 4173
# 브라우저에서 http://127.0.0.1:4173/ 접속
```

`tools/unity_batch.sh`는 `/Applications/Unity/Hub/Editor` 아래의 Unity를 자동
탐색합니다. 다른 경로에 설치했다면 `UNITY_BIN` 환경변수로 지정합니다.
