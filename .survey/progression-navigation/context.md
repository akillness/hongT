## Adjacent Problems

네비게이션을 손대면 같이 걸리는, 이미 존재하는 문제들:

1. **`·`(U+00B7) 글리프 탈락 — 라이브 결함** `direct page retrieval`
   본 조사 중 발견. View 소스 문자열 스캔 결과 printable 문자 **499종**인데
   배포 폰트 `Assets/Resources/Fonts/HudKorean.otf` cmap은 **498종**.
   차집합은 정확히 `·` 하나다. **사용자 가시 문자열 4건**(전부 `HudView.cs`):
   - `:1138` `"1 공격  ·  2 생명  ·  3 민첩"` — 성장 패널 안내
   - `:1196` `"명령 입력: 집중공격 · 방어 · 복귀 · 노바 · 결계 …"` — 콘솔 placeholder
   - `:1246` `"로컬 명령: … · 자유 문장은 …"` — 콘솔 토스트
   - `:1698` `"레벨 업! 피해 +4% · 최대 체력 +6"` — 레벨업 토스트

   추가로 주석 6줄(`HudView.cs:1634,2205` / `GameDirector.cs:309` /
   `LobbyView.cs:58` / `CampaignStore.cs:26,33`)에도 `·`가 있으나 **화면과 무관**하다.
   단, 스캐너 동작을 정확히 보면 주석이 완전히 무해하지는 않다 `[OBSERVED]`:
   `gen_hud_font.sh`의 인용문 정규식은 **파일 전체를 한 번에** 훑으므로 따옴표 짝짓기가
   줄 단위와 달라진다. 실제로 전체 스캔이 잡아내는 `·` 포함 문자열은 위 4건이 아니라
   `구역 정화 · 점수 0 • 유물 0`, `레벨 업! 피해 +4% · 최대 체력 +6`,
   `군단에 함락됐다 · 웨이브 1 도달` 3건이고, 이 중 **2건이 주석 안의 인용구**다.
   즉 **주석이 서브셋 charset에 기여한다**. (Hangul 스윕 `[가-힣]`은 U+00B7을 못 잡으므로
   인용문 경로가 유일한 통로다.)
   → 다만 **주석을 지운다고 안전해지지 않고, 주석만 남겨도 charset에 들어올 수 있다.**

   **정정 — 「폰트 재생성이 해소 경로」는 틀렸다** `[OBSERVED]`
   QA(`QANavBenchmark`)가 원본 폰트를 열어 반증했고 본 레인에서 재확인했다.
   원본 `~/Library/Fonts/NanumBarunGothic.otf` cmap **18,665자**를 조회한 결과:

   | 문자 | 원본 폰트에 존재 | 해소 경로 |
   |---|---|---|
   | `·` U+00B7 | **없음** | **치환뿐** (재생성 불가) |
   | `−` U+2212 | **없음** | **치환뿐** (재생성 불가) |
   | `•` U+2022 | 있음 | — (스크립트가 무조건 주입) |
   | `-` U+002D | 있음 | — |
   | `간` U+AC04 / `≥` U+2265 / `§` U+00A7 / `≤` U+2264 | 있음 | 재생성으로 해소 |

   즉 `·`와 `−`는 **소스 폰트 자체에 글리프가 없어** 서브셋을 몇 번 다시 만들어도
   들어오지 않는다. `gen_hud_font.sh` 27-37행의 검증 블록이 정확히 이 경우를 위해
   `MISSING (source font lacks these — replace in code)`를 출력하고 `SystemExit(1)`
   하도록 짜여 있다 — **스크립트가 이미 "치환하라"고 말하도록 설계돼 있었다.**
   결함은 재생성이 밀린 게 아니라 **이 차단이 우회된 채 배포된 것**이다.

   `docs/RELEASE_NOTES.md:279-281`의 전례(436 glyphs 재생성)는 **원본에 있는 문자**가
   서브셋에서 빠진 사례라 유형이 다르다. 이번 `·`/`−`는 재생성으로 닫히지 않는다.
   **네비게이션 문자열에 `·`를 구분자로 쓰면 그 자리에서 두부가 나며, 폰트를 다시
   만들어도 낫지 않는다.** 대체는 `•`(U+2022) 또는 ASCII `-`.
   조사 산출물이므로 여기서는 기록만 한다.
   - 참고: 계약 문서에 적힌 "497 글리프"와 실측(소스 499 / 폰트 498)이 어긋난다.
     드리프트 폭 1~2로 결론에는 영향 없지만, 수치를 인용할 때는 실측을 쓴다.

1-B. **`−`(U+2212) 글리프 탈락 — `·`보다 높은 등급의 결함** `direct page retrieval`
   QA(`QANavBenchmark`)가 위 `·` 조사에 이어 발견, 본 레인에서 독립 재현.
   서브셋 스캐너를 두 모드로 돌려 폰트 cmap과 대조하면 `[OBSERVED]`:
   ```
   전체 파일 스캔(스크립트 실동작) : 499자 → 누락 [·]
   줄 단위 스캔(직관)             : 499자 → 누락 [·, −]
   대칭차: 줄 단위에만 「−」 / 전체 스캔에만 「§」
   ```
   같은 499자인데 **집합이 다르다.** 전체 파일 정규식은 따옴표 짝짓기가 줄 경계를
   넘어 엇물리면서 한국어 문자열 다수를 놓친다.
   `−`의 출처는 주석이 아니라 **사용자 가시 라벨**이다:
   `HudView.cs:884` `$"Companion cadence −{10 * magnitude}% (min 0.5 s)"`
   (`EmberRestEffectLabel`, 레벨업 준비 제안 라벨). 형제 분기 5개는 전부 ASCII `+`를
   쓰는데 이 한 줄만 U+2212라 **의도적 타이포그래피가 아니라 혼입**으로 보인다.

   **등급이 `·`보다 높은 이유**: `·`는 스크립트가 charset에 넣고 폰트에 없으면
   `SystemExit(1)`로 **차단이라도 한다**. `−`는 스크립트가 **아예 못 본다** →
   charset 미포함 → 서브셋 미포함 → **재생성해도 여전히 누락인데 `coverage: FULL`
   초록**. 위양성이라 탐지 자체가 불가능하다.
   → 검사기를 스크립트와 **동일한** 정규식으로만 짜면 이 사각을 영원히 못 본다
   (그 정규식이 사각의 원인이므로). QA가 T-A8을 **두 모드 합집합**으로 잠갔다:
   (1) 전체 스캔 charset − cmap == ∅, (2) 줄 단위 charset − cmap == ∅,
   (3) 대칭차는 보고 항목(현재 `{−, §}`). 현행 **2/2 실패**.
   대체 문자는 ASCII `-`로 충분하다. 조사 태스크라 수정하지 않고 기록만 한다.

2. **터치 하한 래칫이 그룹 헤더 개수를 제약한다.** `LobbyLayoutTests.cs`가 44 CSS px
   미만 컨트롤의 정확한 집합을 동결한다. 그룹 헤더를 **탭 가능한 컨트롤**로 만들면
   44u가 필요하다. 산술 `[OBSERVED]`:
   - 활성 챕터 3장(210u) + 등급선택(70u) = 본문 280u, 뷰포트 434u → 헤더 예산 154u

- **Hades II (Early Access)** — "플레이어들이 무엇을 우선해야 할지 **'길을 잃었다(lost)'**고
  자주 표현했고, 통화 종류가 너무 많아 압도적이라는 반응. 게임패드 메뉴 내비게이션
  결함도 함께 보고됨." (Reddit / Steam 커뮤니티 정서 종합)
  → Supergiant 대응: **Forget-Me-Not** 자원 추적 기능 추가, 충분히 모였을 때 아이콘
  변경, **Path of Stars 게임패드 내비게이션 개선**, Book of Shadows 개선.
  **패치가 곧 불만의 실재 증거다.**

- **Darkest Dungeon 2 (Altar of Hope)** — "1편 대비 **전략 게임에서 '그라인드페스트'로
  이동**했다는 비판. 모바일/인크리멘털 게임 같다는 표현. 기본 캐릭터 클래스·스킬·
  아이템을 풀려고 반복 런을 강제한다는 **'플레이어 시간 경시(disrespect for player
  time)'** 지적." (커뮤니티 리뷰 종합)
  → 아이러니: Altar of Hope는 2022년 9월 **"장기 진행이 없다"는 초기 불만에 대한
  대응으로 추가된 화면**이다. 화면을 추가했더니 불만이 형태만 바꿔 재발했다.

- **Enter the Gungeon** — "진행 시스템이 **'obtuse'**하다는 지적이 잦다. 비밀 방,
  복잡한 해금 요건에 대한 설명이 거의 없어 **외부 위키/가이드에 의존해야만** 유의미한
  진행을 이해할 수 있다고 느낀다." → Ammonomicon은 **이미 발견한 것의 도감**일 뿐
  해금 힌트를 제공하지 않는다.

- **Vampire Survivors** — "숨은 캐릭터 해금이 **모호한 입력·수수께끼**에 의존해 자연
  플레이로는 사실상 발견 불가. **압도적 다수가 외부 소스에 의존**." → 0.10.0 "The Not
  One" 패치(2022-08-04)에서 **Secrets 메뉴** 추가로 힌트 제공. 단, 이 메뉴 자체가
  Forbidden Scrolls of Morbane 유물 해금 뒤에 있고, 그 유물은 3스테이지 Hyper Mode
  해금 후 The Bone Zone 보스를 잡아야 나온다. **힌트를 해금 뒤에 두면 그건 힌트가 아니다.**

- **Wizard of Legend** — "**pool 기반 해금 시스템을 게임이 명시적으로 설명하지 않는다.**
  왜 상점에 어떤 아이템이 안 나오는지 이해 못 함. 실제 요건은 '현재 풀 아이템의 절반가량
  구매'인데 이 수치 조건이 화면에 없다." → **수치 조건을 갖고 있으면서 안 보여주는** 형태.

- **Loop Hero** — "**인접(adjacency) 요건에 대한 직접적 UI 피드백이 제한적**이어서
  플레이어가 '막혔다' 또는 '배치를 잘못했다'고 느끼는 일이 흔하다."
  → 규칙이 존재하는데 화면에 없으면 규칙이 아니라 함정이다.

- **Risk of Rain 2** — "해금 조건이 **모호하고 운 의존적**이라는 비판. 로그북 완성은
  저확률 드롭 의존이라 '그라인드'로 자주 지목." → 단, 조건 **문자열 자체는** 로그북에
  Challenge 이름 + 설명으로 표시된다. **불만의 대상이 '조건 미표시'가 아니라 '조건 달성
  난이도'**라는 점에서 위 사례들과 구분된다. 이 구분이 중요하다(§solutions.md Contradictions).

- **Children of Morta** — "진행이 **'treadmill'**이며 다음 지역을 버티려고 골드·경험치를
  모으느라 던전을 반복하게 만든다는 지적. 인위적 시간 늘리기라는 표현."

- **Skul: The Hero Slayer** — "초반 Dark Quartz 축적이 느려 **'early-game wall'**로
  느껴진다는 불만. 비용 대비 체감 가치가 낮다는 반응."
